# putapin-mod

## Description

A Claude Code mod that asks on startup:

```
Resume prior session? (Y/n)
```

- **Y** (or just Enter — the default) resumes the most recent Claude Code session for the current directory, picking up exactly where it was left.
- **n** does nothing: Claude Code starts a fresh session as usual.
